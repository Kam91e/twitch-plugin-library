# Twitch Plugin Knowledge Library

A curated knowledge base for Twitch streamers. Find and compare Twitch Extensions (plugins) organised by Twitch's official categories.

## What This Is

This library documents Twitch Extensions — plugins that you can install directly from your Twitch dashboard. Each plugin has a dedicated page with:

- **Quick Start** — get it running in under 2 minutes
- **Features** — what it does
- **Configuration** — all the settings for power users
- **Tips & Tricks** — pro-tips and hidden features
- **Alternatives** — similar plugins in the same category

## How to Navigate

| File | Purpose |
