# Twitch Extension Categories

This file lists the 8 official Twitch Extension categories and their subcategories. It serves as the single source of truth for plugin taxonomy in this library.

---

## Extensions for Games
Extensions built to work with specific games.

**Directory:** `plugins/extensions-for-games/`

| Subcategory | Description | Directory |
|---|---|---|
| `game-integrations` | Extensions that integrate directly with a specific game (e.g., Dota 2, League of Legends, Fortnite) | `plugins/extensions-for-games/game-integrations/` |
| `live-stats` | Real-time statistics overlays showing K/D, MMR, damage, or other in-game metrics | `plugins/extensions-for-games/live-stats/` |
| `match-history` | Show recent matches, win/loss streaks, and performance history | `plugins/extensions-for-games/match-history/` |
| `character-builds` | Item builds, skill trees, and character optimisation guides | `plugins/extensions-for-games/character-builds/` |

## Schedule & Countdowns
Share your streaming schedule and encourage your viewers to keep coming back.

**Directory:** `plugins/schedule-and-countdowns/`

| Subcategory | Description | Directory |
|---|---|---|
| `stream-schedule` | Display your streaming schedule so viewers know when you go live | `plugins/schedule-and-countdowns/stream-schedule/` |
| `countdown-timers` | Countdown timers for stream start, breaks, or special events | `plugins/schedule-and-countdowns/countdown-timers/` |
| `upcoming-events` | Show upcoming streams, marathons, or community events | `plugins/schedule-and-countdowns/upcoming-events/` |

## Loyalty and Recognition
Reward viewers for showing their support with leaderboards and other tools.

**Directory:** `plugins/loyalty-and-recognition/`

| Subcategory | Description | Directory |
|---|---|---|
| `channel-points` | Channel points systems, custom redemptions, and reward management | `plugins/loyalty-and-recognition/channel-points/` |
| `leaderboards` | Top chatters, top supporters, and leaderboard displays | `plugins/loyalty-and-recognition/leaderboards/` |
| `achievements` | Badges, trophies, and milestone achievements for viewers | `plugins/loyalty-and-recognition/achievements/` |
| `shoutouts` | Automated or manual shoutout tools for community recognition | `plugins/loyalty-and-recognition/shoutouts/` |
| `user-management` | Viewer role management, VIP tools, and user lists | `plugins/loyalty-and-recognition/user-management/` |
| `viewer-profiles` | Individual viewer statistics, profile cards, and personal engagement metrics | `plugins/loyalty-and-recognition/viewer-profiles/` |
| `emotes-and-badges` | Display channel emotes and badges, including subscriber tiers and third-party emote support (BTTV, FFZ, 7TV) | `plugins/loyalty-and-recognition/emotes-and-badges/` |

## Streamer Tools
Tools that help you improve your stream so that you can focus on making great content.

**Directory:** `plugins/streamer-tools/`

| Subcategory | Description | Directory |
|---|---|---|
| `overlays` | Stream layout widgets, graphics, and visual overlays | `plugins/streamer-tools/overlays/` |
| `alerts` | Follow, sub, raid, donation, and other notification alerts | `plugins/streamer-tools/alerts/` |
| `scene-management` | Scene switching, source management, and OBS integration | `plugins/streamer-tools/scene-management/` |
| `chat-tools` | Chat commands, emotes, moderation, and chat management | `plugins/streamer-tools/chat-tools/` |
| `audio-tools` | Microphone, audio mixing, sound effects, and voice processing | `plugins/streamer-tools/audio-tools/` |
| `monetization` | Donations, subscriptions, merchandise, and revenue tools | `plugins/streamer-tools/monetization/` |
| `analytics` | Stream statistics, viewer metrics, and growth tracking | `plugins/streamer-tools/analytics/` |
| `accessibility` | Captions, TTS, colour-blind modes, and accessibility tools | `plugins/streamer-tools/accessibility/` |

## Viewer Engagement
Fun ways to allow your audience to engage with you.

**Directory:** `plugins/viewer-engagement/`

| Subcategory | Description | Directory |
|---|---|---|
| `hype-trains` | Hype train events, progress bars, and rewards | `plugins/viewer-engagement/hype-trains/` |
| `raids` | Raid tools, co-streaming, and host/raid management | `plugins/viewer-engagement/raids/` |
| `viewer-goals` | Follower goals, sub goals, donation goals with progress displays | `plugins/viewer-engagement/viewer-goals/` |
| `predictions` | Channel predictions and viewer betting with channel points | `plugins/viewer-engagement/predictions/` |
| `quests` | Viewer challenges, quests, and community goals | `plugins/viewer-engagement/quests/` |
| `interactive-overlays` | Interactive overlay elements triggered by viewers (stickers, drawings, animations) | `plugins/viewer-engagement/interactive-overlays/` |
| `all-in-one-interactions` | Comprehensive interaction platforms combining TTS, memes, alerts, and other engagement tools | `plugins/viewer-engagement/all-in-one-interactions/` |
| `gameplay-interaction` | Plugins that let viewers directly influence or control the streamer's gameplay in real time | `plugins/viewer-engagement/gameplay-interaction/` |

## Music
Show your viewers what song you're playing or let them suggest what to play next.

**Directory:** `plugins/music/`

| Subcategory | Description | Directory |
|---|---|---|
| `now-playing` | Display the currently playing song on stream | `plugins/music/now-playing/` |
| `song-requests` | Let viewers request songs via chat or channel points | `plugins/music/song-requests/` |
| `playlist-manager` | Manage playlists, queue tracks, and blacklist songs | `plugins/music/playlist-manager/` |
| `copyright-checker` | Detect copyrighted music and avoid DMCA strikes | `plugins/music/copyright-checker/` |

## Polling & Voting
Get feedback from your audience.

**Directory:** `plugins/polling-and-voting/`

| Subcategory | Description | Directory |
|---|---|---|
| `polls` | Quick polls for viewer opinions | `plugins/polling-and-voting/polls/` |

## Games in Extensions
Extensions that are games themselves, played on Twitch.

**Directory:** `plugins/games-in-extensions/`

| Subcategory | Description | Directory |
|---|---|---|
| `chat-games` | Games played through chat messages and commands | `plugins/games-in-extensions/chat-games/` |
| `mini-games` | Small games in the stream overlay | `plugins/games-in-extensions/mini-games/` |
| `gambling-games` | Games using channel points or virtual currency with risk/reward | `plugins/games-in-extensions/gambling-games/` |
| `trivia` | Trivia and quiz games for viewer participation | `plugins/games-in-extensions/trivia/` |
