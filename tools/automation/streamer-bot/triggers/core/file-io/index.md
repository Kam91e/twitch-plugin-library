# Core — File I/O

> Triggers for file I/O events, including when a file tail detects a change.

## File Tail

### File Tail Changed

**Location:** `Core > File I/O > File Tail > File Tail Changed`
**Add behavior:** dialog — opens a config dialog on selection (evidence: `trigger-Core-File-IO-File-Tail-Changed-dialog-uia.txt`) (see `creation-flows-catalog.txt`)
**Description:** Trigger for a Change from a File Tail. File tails are configured under [Services > File Tails](../../../services.md#file-tails).
**Parameters:** App-verified from `trigger-Core-File-IO-File-Tail-Changed-dialog-uia.txt`, `trigger-Core-File-IO-File-Tail-Changed-dialog.png` (Add Trigger - Core > File IO > File Tail > Changed, ~600×140): `File Tail` (select), `Create File Tail` (button); Ok/Cancel present.
**Variables:** Not documented in official docs
