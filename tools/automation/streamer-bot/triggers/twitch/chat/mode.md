# Twitch — Chat > Mode

> Triggers for Twitch chat mode changes: emote, follower, slow, subscriber, and unique modes being toggled on, off, or changed.

## Emote Mode Off

**Location:** `Twitch > Chat > Mode > Emote Mode Off`
**Add behavior:** direct — added immediately, no dialog (see `creation-flows-catalog.txt`)
**Description:** Trigger for when the Twitch Emote Mode is turned Off
