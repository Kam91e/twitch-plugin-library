# Twitch — Emotes

> Triggers for third-party emote providers: BetterTTV and SevenTV emotes being added to or removed from the channel.

## BetterTTV Emote Added

**Location:** `Twitch > Emotes > BetterTTV Emote Added`
**Add behavior:** direct — added immediately, no dialog (see `creation-flows-catalog.txt`)
**Description:** Trigger for when a BetterTTV emote has been added to the channel

**Parameters:** Not documented in official docs

**Variables:** Not documented in official docs
