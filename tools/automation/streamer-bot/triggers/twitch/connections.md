# Twitch — Connections

> Triggers for Twitch connection lifecycle events: the bot and broadcaster chat clients, broadcaster EventSub, and broadcaster authentication.

## Bot Chat Connected

**Location:** `Twitch > Connections > Bot Chat Connected`
**Add behavior:** direct — added immediately, no dialog (see `creation-flows-catalog.txt`)
**Description:** Trigger for when the Chat Client is Connected for the Twitch Bot

**Parameters:** Not documented in official docs

**Variables:** Not documented in official docs
