# Twitch — Guest Star

> Triggers for Twitch Guest Star: session begin and end, guest updates, and settings changes.

## Guest Star Guest Update

**Location:** `Twitch > Guest Star > Guest Star Guest Update`
**Add behavior:** dialog — opens a config dialog on selection (evidence: `trigger-Twitch-Guest-Star-Guest-Star-Guest-Update-dialog-uia.txt`; see `creation-flows-catalog.txt`)
**Description:** Trigger for when a Guest Star guest receives an update

**Parameters:** App-verified from `trigger-Twitch-Guest-Star-Guest-Star-Guest-Update-dialog-uia.txt`, `trigger-Twitch-Guest-Star-Guest-Star-Guest-Update-dialog.png` (Add Trigger - Twitch > Guest Star > Guest Star Guest Update, ~600×140): `State` (select); Ok/Cancel present.

**Variables:** Not documented in official docs
