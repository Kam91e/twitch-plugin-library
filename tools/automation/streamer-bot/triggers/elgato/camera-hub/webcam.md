# Elgato — Camera Hub > Webcam

> Triggers fired when an Elgato Camera Hub webcam changes state or settings: activation, exposure, focus, white balance, orientation effects and image adjustments.

## Webcam Activated

**Location:** `Elgato > Camera Hub > Webcam > Webcam Activated`
**Add behavior:** direct — added immediately, no dialog (see `creation-flows-catalog.txt`)
**Description:** When a Webcam is ready for use in Elgato CameraHub

**Parameters:** Not documented in official docs

**Variables:** Not documented in official docs
