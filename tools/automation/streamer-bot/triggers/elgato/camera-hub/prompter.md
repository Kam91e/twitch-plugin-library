# Elgato — Camera Hub > Prompter

> Triggers fired when the Elgato Camera Hub Prompter changes state or settings: connection, auto-scroll, display appearance, crosshair and script/chapter selection.

## Auto Scroll Chapter Disabled

**Location:** `Elgato > Camera Hub > Prompter > Auto Scroll Chapter Disabled`
**Add behavior:** direct — added immediately, no dialog (see `creation-flows-catalog.txt`)
**Description:** When the auto scroll for chapters is disabled
