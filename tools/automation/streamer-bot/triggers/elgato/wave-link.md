# Elgato — Wave Link

> Triggers fired by the Elgato Wave Link integration in Streamer.bot: connection state, input/microphone/filter/output events and level meters.

Wave Link triggers fire when Elgato Wave Link audio devices change state: connection, inputs (mute, name, volume, level meters), microphones (gain, balance, mute, output volume, settings), filters (added, changed, deleted, bypass state) and outputs (mute, volume, switching, selected output). Official documentation: <https://docs.streamer.bot/api/triggers/elgato/wave-link>
