# Elgato

> Triggers fired by Elgato hardware integrations in Streamer.bot: Camera Hub devices (prompter, webcam), Wave Link audio mixing and Stream Deck.

These triggers let Streamer.bot react to Elgato hardware events: Camera Hub prompter and webcam state changes, Wave Link input, microphone, filter and output events, and Stream Deck connection and info events. Official documentation: <https://docs.streamer.bot/api/triggers/elgato>

## Groups

- [Camera Hub](camera-hub/index.md) — Prompter, webcam and integration connection triggers.
- [Wave Link](wave-link.md) — Wave Link connection, input, microphone, filter and output triggers.
