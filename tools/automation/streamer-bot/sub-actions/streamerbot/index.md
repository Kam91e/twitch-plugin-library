# Streamer.bot

Sub-actions for communicating between Streamer.bot instances via the Streamer.bot Website Integration — remote signals and triggers.

**Location:** `Streamer.bot > Decks > Deck Notify`
**Add behavior:** dialog — opens a config dialog on selection (evidence: `subaction-Streamer-bot-Decks-Deck-Notify-dialog-uia.txt`) (see `creation-flows-catalog.txt`)
**Description:** Send a notification to a Streamer.bot Deck

**Parameters:** App-verified from `subaction-Streamer-bot-Decks-Deck-Notify-dialog-uia.txt`, `subaction-Streamer-bot-Decks-Deck-Notify-dialog.png` (Add SubAction - Streamer.bot > Decks > Deck Notify, ~600×304): `Deck` (text), `Not Connected!` (button), `Title` (text), `Description` (text), `Color` (text), `SoundId` (text), `Test` (button), `Not Connected` (button); Ok/Cancel present.

### Wait For Remote Signal

**Location:** `Streamer.bot > Remote > Wait For Remote Signal`
**Add behavior:** dialog — opens a config dialog on selection (evidence: `subaction-Streamer-bot-Remote-Wait-For-Remote-Signal-dialog-uia.txt`) (see `creation-flows-catalog.txt`)
**Description:** Wait for a remote signal from another Streamer.bot instance. Notes: requires the Streamer.bot Website Integration; if the subaction times out, only the `signalTimeout` will be populated with a value of `True`.

**Parameters:** App-verified from `subaction-Streamer-bot-Remote-Wait-For-Remote-Signal-dialog-uia.txt`, `subaction-Streamer-bot-Remote-Wait-For-Remote-Signal-dialog.png` (Add SubAction - Streamer.bot > Remote > Wait For Remote Signal, ~600×271): `Not Connected!` (text), `Signal Name` (text), `Overwrite Variables` (text), `Timeout` (text), `If timeout is left blank, it defaults to 30 seconds (or 30,000ms)` (button), `Not Connected` (button); Ok/Cancel present.

**Variables:** Not documented in official docs
