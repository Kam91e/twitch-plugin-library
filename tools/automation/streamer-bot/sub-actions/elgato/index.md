# Elgato

> Sub-actions for controlling Elgato hardware from Streamer.bot: Camera Hub devices (prompter, webcam, EpocCam), Wave Link audio mixing, and Stream Deck keys and dials.

These sub-actions let Streamer.bot automate Elgato hardware directly: drive the Camera Hub Prompter and webcams, switch EpocCam settings, adjust Wave Link inputs, microphones, filters and outputs, and update Stream Deck key and dial appearance and feedback. Official documentation: <https://docs.streamer.bot/api/sub-actions/elgato>

## Groups

- [Camera Hub](camera-hub/index.md) — Prompter, webcam and EpocCam control sub-actions.
- [Stream Deck](stream-deck.md) — Modify Stream Deck key/dial state, title, background, value and feedback.
- [Wave Link](wave-link.md) — Control Wave Link inputs, microphones, filters, outputs and volumes.
