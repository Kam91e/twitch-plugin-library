# Elgato — Camera Hub > EpocCam

> Sub-actions to control Elgato EpocCam through Camera Hub: AR lens, bitrate, camera selection and flash mode.

## EpocCam Set AR Lens

**Location:** `Elgato > Camera Hub > EpocCam > Set AR Lens`
**Add behavior:** dialog — opens a config dialog on selection (evidence: `subaction-Elgato-Camera-Hub-EpocCam-Set-AR-Lens-dialog-uia.txt`; see `creation-flows-catalog.txt`)
**Dependency:** requires a configured Elgato CameraHub connection
**Description:** Enables or Disables the AR Lens from the drop-down menu

**Parameters:** App-verified from `subaction-Elgato-Camera-Hub-EpocCam-Set-AR-Lens-dialog-uia.txt`, `subaction-Elgato-Camera-Hub-EpocCam-Set-AR-Lens-dialog.png` (Add SubAction - Elgato > Camera Hub > EpocCam > Set AR Lens, ~600×124): `AR Lens` (button), `Elgato CameraHub is Not Connected!` (button), `Test` (button), `Not Connected` (button); Ok/Cancel present.

**Variables:** Not documented in official docs
