# Elgato — Camera Hub > Webcam

> Sub-actions to control Elgato Camera Hub webcam settings: exposure, white balance, focus, pan and tilt, zoom, and image adjustments such as contrast, saturation and sharpness.

## Webcam Set Anti Flicker

**Location:** `Elgato > Camera Hub > Webcam > Set Anti Flicker`
**Add behavior:** dialog — opens a config dialog on selection (evidence: `subaction-Elgato-Camera-Hub-Webcam-Set-Anti-Flicker-dialog-uia.txt`; see `creation-flows-catalog.txt`)
**Dependency:** requires a configured Elgato CameraHub connection
**Description:** Sets the desired anti flicker amount from the drop-down menu

**Parameters:** App-verified from `subaction-Elgato-Camera-Hub-Webcam-Set-Anti-Flicker-dialog-uia.txt`, `subaction-Elgato-Camera-Hub-Webcam-Set-Anti-Flicker-dialog.png` (Add SubAction - Elgato > Camera Hub > Webcam > Set Anti Flicker, ~600×139): `Anti-flicker` (button), `Elgato CameraHub is Not Connected!` (button), `Test` (button), `Not Connected` (button); Ok/Cancel present.

**Variables:** Not documented in official docs
