# SE.Live

> SE.Live is a free multi-streaming plugin that runs inside OBS Studio, adding multi-stream, multi-chat, custom canvases, and management docks directly to your broadcasting software.

## Overview

SE.Live is not a standalone streaming application — it is an **OBS Studio plugin**, a dock and panel layer that installs into OBS Studio itself. It is installed from the StreamElements **Desktop apps** sidebar option. Once installed, SE.Live adds streaming and management features directly inside OBS: multi-streaming, multi-chat, custom canvases, and docks. SE.Live is available on **Windows** and on **macOS (beta)**. The Desktop apps page also lists **Ground Control**, a separate companion app available on macOS as well.

## Key Features

- **Free unlimited multi-streaming** — broadcast simultaneously to Twitch, TikTok, YouTube, X, KICK, Trovo, and custom RTMP outputs. Uses native platform logins, so no stream keys are needed
- **Unified multi-chat** — chat from Twitch, YouTube, X, and KICK consolidated into one dock
- **Custom canvases** — unlimited horizontal and vertical layouts with linked scenes, for switching between just-chatting and gameplay, or targeting vertical platforms (TikTok/Shorts)
- **Per-platform audio tracks** — assign different audio tracks per platform (for example, music on the live stream but muted on VOD platforms) to avoid copyright strikes
- **Docks** — Activity feed, Elements Control Center (add widgets from the gallery), Media Request, Multi-Chat

## Installation / Setup

1. From the dashboard sidebar, go to **Streaming tools → Desktop apps**
2. Download and install SE.Live (Windows or macOS beta)
3. Restart OBS Studio — the StreamElements docks appear in the Dock menu
4. Log in with the same StreamElements account in the plugin

## Configuration

### Multi-streaming

- Add each platform via native login; streams are selected per platform
- No stream keys required — each platform is connected through its own login
- Supports custom RTMP outputs in addition to the built-in platform list

### Custom Canvases

- Create a canvas and link scenes to it
- Switch layouts without duplicating scenes
- Unlimited horizontal and vertical layouts — handy for vertical platforms (TikTok/Shorts) and for toggling between just-chatting and gameplay setups

### Audio Tracks

- Per-platform track selection in stream settings
- Useful for VOD safety: keep music on the live track while muting it on platforms where the stream is saved and re-watched

### Docks

- **Activity feed** — shows stream events and activity
- **Elements Control Center** — add and customise widgets directly from the StreamElements widget gallery
- **Media Request** — manage song requests without opening a browser (see [Media Request](media-request.md))
- **Multi-Chat** — combined chat from Twitch, YouTube, X, and KICK in one dock

## Tips

- Use custom canvases to keep a single set of scenes while streaming to vertical platforms
- Per-platform audio tracks prevent DMCA strikes from music on VOD or multi-platform streams
- Prefer the Media Request dock over the website for managing song requests while live (see [Media Request](media-request.md))
- You can run SE.Live alongside other OBS plugins; the dashboard remains the management hub (see [Overview](overview.md))
