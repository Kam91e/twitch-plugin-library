# Meld Studio — Meld Spark

> Meld Spark is an AI-powered overlay and widget builder that turns natural language descriptions into living stream elements in seconds.

## What Is Meld Spark?

Meld Spark is a generative AI feature built into Meld Studio that creates overlays, alerts, mini-games, timers, and widgets directly on your canvas. Instead of downloading a theme, editing HTML/CSS, or configuring a widget from scratch, you simply describe what you want and Spark builds it live.

Spark is trained on streaming overlay patterns and understands streaming concepts — you can say "a retro-style alert box for subs" or "a progress bar for my follower goal" and it will produce a working element.

## How It Works

1. Open Meld Studio and click the **Spark** button in the toolbar
2. Describe the element you want in natural language (e.g., "a glowing neon alert for cheers with a purple colour scheme")
3. Spark builds the element on your canvas in seconds
4. Drag, resize, and customise the generated element using Meld Studio's standard tools
5. The element is fully functional — it responds to Twitch events, alerts, and interactions immediately

### Examples of Spark Prompts

| Prompt | Result |
|---|---|
| "A retro arcade-style sub alert with pixel font" | Animated sub notification with pixel aesthetic |
| "A follower goal progress bar with a cyberpunk theme" | Themed progress widget |
| "A chat overlay with rounded corners and a subtle glow" | Styled chat display |
| "A simple countdown timer for my BRB scene" | Working countdown widget |
| "A mini-game where viewers click to pop balloons" | Interactive viewer game |

## Spark Plug for OBS

Meld Spark is also available as an OBS plugin for users who want to keep OBS Studio as their main streaming software while using Spark for overlay creation.

1. Download the Spark Plug for OBS from [meldstudio.co](https://meldstudio.co/download/referral/?product=obs-spark-plugin)
2. Install the plugin — OBS will detect it automatically
3. Add a new **Meld Spark** source in OBS
4. Describe your overlay directly in the OBS source properties
5. Spark builds the element inside OBS — no Meld Studio installation required

## Customisation

Spark-generated elements are fully customisable after creation:

- **Position and scale**: drag and resize on canvas like any other source
- **Colours and fonts**: change via the standard property panel
- **Behaviour**: attach Spark elements to Twitch events, configure their responses
- **Combining**: layer multiple Spark elements for complex overlay compositions

## Tips & Tricks

- Be specific in your Spark prompts — "a minimal chat overlay with white text on transparent background" gets better results than "a chat thing"
- Spark is great for rapid prototyping: generate an overlay, see if you like the direction, then fine-tune or regenerate
- Combine Spark elements with Meld Studio's built-in widgets for layered effects
- The OBS Spark Plug is perfect if you're happy with OBS but want AI-powered overlay creation without switching software
- Spark learns from usage — the more you use it, the better it understands your style preferences
