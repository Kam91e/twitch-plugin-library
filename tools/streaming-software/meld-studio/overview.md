# Meld Studio

> A native streaming application built from the ground up with cloud multi-streaming, integrated multi-chat, and an AI-powered overlay builder — no OBS fork, no plugins required.

## Overview

Meld Studio is a modern streaming application written specifically for Windows (DirectX 12) and macOS (Apple Silicon native). Unlike OBS, Streamlabs Desktop, or other forks, Meld Studio is built from scratch by a dedicated team of creators. It is updated every two weeks based on community feedback.

Meld Studio's key differentiators are its cloud-based multi-streaming service (Meld Multi), which distributes your stream to multiple platforms without any CPU load on your computer, its integrated multi-chat that consolidates Twitch, YouTube, and Kick chat in one panel, and Meld Spark — an AI feature that builds overlays, alerts, and widgets from natural language descriptions. It is free forever with no watermarks or time limits, with a Pro tier available.

## Key Features

- **Native architecture** — built from scratch (not an OBS fork), optimised for modern hardware
- **Cloud multi-streaming** — stream to Twitch, YouTube, Kick, and custom RTMP simultaneously with zero CPU load
- **Multi-chat** — Twitch, YouTube, and Kick chat in a single built-in panel
- **Meld Spark AI** — describe an overlay in natural language, and it appears on your canvas
- **Built-in widgets & alerts** — chat overlay, alerts, donation goals, follower/sub notifications — no external tools needed
- **Multi-track audio** — source routing, live monitoring, per-track recording for post-production
- **Multi Canvas** — different layouts for horizontal (main) and vertical (portrait) outputs
- **Stream Manager** — change stream title, category, tags without leaving the app
- **Integrations** — VTube Studio, Streamer.bot, Stream Deck, Lumia Stream, Mix It Up
- **Frequent updates** — new features every two weeks based on community feedback

## Installation / Setup

1. Download Meld Studio from [meldstudio.co](https://meldstudio.co)
2. Run the installer — Meld Studio is available for Windows and macOS
3. Launch Meld Studio and go through the onboarding flow to connect your streaming accounts
4. Connect Twitch, YouTube, or Kick in **Settings** → **Platforms**
5. Create your first scene: add sources (game capture, webcam, images) to the canvas
6. Use Meld Spark to add overlays, or drag from the widget gallery
7. Click **Go Live** to start streaming — or use Meld Multi for cloud distribution

## Twitch Integration

Meld Studio connects to Twitch natively through the Stream Manager panel. You can change your stream title, category, tags, and thumbnail directly within Meld Studio. Chat appears in the built-in multi-chat panel alongside YouTube and Kick messages. All Twitch events (follows, subs, bits) trigger Meld Studio's built-in alert system without any third-party service.

## Configuration

- **Scene management**: add sources, arrange layers (2D and Z-depth), set transitions, use move transitions
- **Canvas settings**: configure main and portrait layouts with independent scenes and sources
- **Meld Multi**: enable cloud multi-streaming, toggle platforms on/off per session
- **Audio mixer**: per-source volume, routing to specific output tracks, live monitoring, compression and gate
- **Widget gallery**: browse and add built-in alerts, chat overlay, donation goals, follower/sub counters
- **Hotkeys**: assign keyboard shortcuts for scene switching, source visibility, streaming controls
- **Integrations**: configure VTube Studio (Spout2), Streamer.bot, Stream Deck, Lumia Stream connections

## Tips & Tricks

- Meld Multi is especially useful if your PC struggles with the CPU load of multi-streaming — the encoding happens in the cloud
- Use Multi Canvas to send a full-screen gaming view to Twitch and a vertical webcam-focused view to TikTok simultaneously
- Meld Spark is great for quickly prototyping overlays — describe what you want, then fine-tune manually
- The built-in multi-chat means you can retire Restream Chat or other third-party chat aggregation tools
- For recording, use multi-track audio to capture game audio, mic, and Discord on separate tracks for flexible editing

## Alternatives

- **OBS Studio**: The industry standard — more plugins and community resources, but requires more manual setup
- **Streamlabs Desktop**: More beginner-friendly with built-in overlays and Cloudbot, but based on OBS and heavier
- **StreamElements**: Browser-based overlay platform with a wider widget selection, but no desktop application
- **PolyPop**: Game-engine-powered streaming with 3D interactive overlays — very different approach
