# Streamlabs Desktop — Alerts & Cloudbot

> Streamlabs Desktop comes with a built-in alert system and an integrated chatbot (Cloudbot) — both configurable without third-party services.

## Alert System

Streamlabs Desktop includes a comprehensive alert system that notifies you and your viewers when events happen on your stream. Alerts are displayed as on-screen animations with optional sound effects.

### Supported Events

- **New follower** — welcome new followers with a custom animation
- **New subscriber** — highlight subscriber milestones (tier 1, 2, 3)
- **Bits / Cheers** — celebrate cheer events with escalating animations
- **Tips / Donations** — real-time tip notifications via Streamlabs tipping
- **Host** — thank hosts for sharing your stream
- **Raid** — welcome raiding communities
- **Channel points** — trigger alerts for channel point redemptions

### Customisation

- **Visual style**: choose from overlay themes or create custom alert designs
- **Animation**: select animation style (slide, fade, bounce, scale) and duration
- **Sound**: upload custom sound files or choose from the built-in library
- **Text**: customise the message template, font, colour, and effects
- **Variations**: create different alert appearances based on event severity (e.g., bigger alert for tier 3 sub)

## Cloudbot

Cloudbot is Streamlabs' free integrated chatbot that runs in the cloud — it stays online even when your streaming software is closed. It handles moderation, engages viewers, and automates repetitive tasks.

### Moderation

- **Spam protection**: filter repeated messages, links, and caps
- **Blacklist**: block specific words, phrases, or patterns
- **Ban management**: automatic timeout or ban for rule violations
- **Permissions**: assign moderator status to trusted viewers
- **CAPTCHA**: require new chatters to solve a CAPTCHA to reduce bot raids

### Custom Commands

- **Built-in commands**: !so (shoutout), !uptime, !followage, !game, !title
- **Custom commands**: create your own with variable responses (user name, stream uptime, etc.)
- **Command cooldowns**: set per-user and global cooldowns to prevent spam

### Viewer Engagement

- **Giveaways**: schedule automatic giveaways with configurable entry conditions (follow, share, etc.)
- **Mini-games**: built-in games like Heist, Slot Machine, Duels with loyalty points
- **Loyalty points**: viewers earn points for watching, spend on rewards or games
- **Song requests**: let viewers request songs (requires Spotify connection)

## Configuration

1. Open Streamlabs Desktop and click on the **Alert Box** or **Cloudbot** icon in the source toolbar
2. For alerts: choose which events to display, customise appearance per event type
3. For Cloudbot: enable in **Settings** → **Cloudbot**, then configure moderation rules and commands
4. Alert settings sync across your Streamlabs account — changes apply everywhere

## Tips & Tricks

- Create different alert variations for different sub tiers — make tier 3 feel special
- Use Cloudbot's loyalty points to encourage viewership — viewers stay longer to earn rewards
- Set up a !discord command so viewers can easily find your community
- Giveaway mode works great for milestone celebrations — set it to trigger at a specific follower count
- Cloudbot runs in the cloud, so commands and moderation work even when you're offline
