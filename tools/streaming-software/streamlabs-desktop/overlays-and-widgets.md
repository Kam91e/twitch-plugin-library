# Streamlabs Desktop — Overlays & Widgets

> Streamlabs Desktop includes a library of hundreds of free and premium overlay themes, plus interactive widgets that engage viewers and display stream stats.

## Overlay Themes

Streamlabs Desktop comes with one of the largest collections of ready-to-use overlay themes, all accessible from within the application.

### Free Themes

- Hundreds of free themes across categories: gaming, IRL, minimalist, esports, retro, modern
- Each theme includes coordinated alert boxes, chat boxes, scene backgrounds, and widgets
- Themes are installed with one click and applied automatically to your scenes

### Premium Themes (Ultra)

- Exclusive themes from professional designers
- More elaborate animations, custom assets, and unique layouts
- New premium themes added regularly
- Ultra subscription ($27/mo or $179/yr) unlocks all premium themes

### Customisation Editor

- Modify colours, fonts, and animations of any theme
- Adjust widget positions, sizes, and opacity
- Show/hide individual elements within a theme
- Preview changes in real time before applying

## Widgets

Widgets are interactive overlay elements that display real-time information or engage viewers.

### Available Widgets

| Widget | Purpose |
|---|---|
| **Chat Box** | Display live chat on stream with custom styling |
| **Event List** | Recent followers, subs, tips, hosts in a scrolling list |
| **Tip Goal** | Progress bar toward a tip goal |
| **Follower Goal** | Progress toward a follower milestone |
| **Subscription Goal** | Progress toward a subscriber goal |
| **Bit Goal** | Progress toward a bit goal |
| **Tip Ticker** | The most recent tips from your viewers |
| **The Jar** | A jar that catches bits, tips, subs, and more |
| **Stream Boss** | Interactive widget where viewers compete for "boss" status |
| **Viewer Count** | Live viewer counter (optional) |
| **Spin Wheel** | Viewers spin a custom wheel to win prizes or incentives |
| **Sponsor Banner** | Rotating media to display your socials, sponsorships, or CTAs |
| **Media Share** | Viewers tip to share videos on your stream |
| **Song Requests** | Display currently requested songs |
| **Streamlabs Charity Donation Goal** | A charity donation goal for viewers to help you reach |
| **Poll** | Viewers vote on a result |
| **Emote Wall** | Displays and animates emotes from chat |
| **Chat Highlight** | Highlights chat messages from your viewers |
| **Custom Widget** | Use HTML, CSS, and JavaScript to create a custom widget |
| **Credits** | End-of-stream credits rolling list of thanks |

### Configuring Widgets

1. In Streamlabs Desktop, click the **+** button in Sources
2. Select the desired widget from the Streamlabs section
3. The widget appears on your scene — drag to position and resize
4. Double-click the widget or click the gear icon to open customisation options
5. Each widget has its own settings panel for colours, fonts, animations, and data source

## Importing and Exporting

- **Import**: load overlay configurations from the Streamlabs community or from backup files
- **Export**: save your complete overlay setup (themes + widget settings) as a single file
- **Sync**: overlay settings sync across your Streamlabs account automatically

## Tips & Tricks

- Start with a free theme that fits your stream's vibe, then gradually customise colours and fonts
- The Event List widget is underrated — it gives lurkers a reason to follow so they appear on screen
- Use the Tip Tracker combined with donation goals to encourage tipping during charity streams
- Export your overlay setup before major changes — easy rollback if something breaks
- Combine with Streamlabs Desktop's scene system: have different overlay setups for starting soon, live, and BRB scenes
