## ADDED Requirements

### Requirement: Document poll.ma.pe overview
The tool document SHALL explain that poll.ma.pe is a free web-based polling service that integrates with Twitch chat and provides themed overlays for OBS Browser Source.

#### Scenario: Reader understands what poll.ma.pe is
- **WHEN** a reader opens the poll.ma.pe tool document
- **THEN** they SHALL understand it is a web service, not a Twitch Extension or desktop app

### Requirement: Document key features
The tool document SHALL list at least: Twitch chat voting, themed overlays (game-specific themes like Dota 2, Rocket League, etc.), OBS Browser Source embed, chat bot integration (pollMapeBot), real-time results, and multiple voting modes (single choice, multiple choice).

#### Scenario: Features are enumerated
- **WHEN** a reader reads the Key Features section
- **THEN** they SHALL see a comprehensive list of poll.ma.pe capabilities

### Requirement: Document setup process
The tool document SHALL explain how to: visit poll.ma.pe, connect with Twitch, create a poll, configure the Browser Source URL in OBS, and manage polls through the dashboard.

#### Scenario: Beginner can set up their first poll
- **WHEN** a streamer follows the setup guide
- **THEN** they SHALL be able to display a poll overlay on their stream with chat voting

### Requirement: Include alternatives
The tool document SHALL list alternatives: Streamlabs Polls, StreamElements Polls, StrawPoll (manual), and when to choose each.

#### Scenario: Reader can compare polling options
- **WHEN** a reader finishes the document
- **THEN** they SHALL know what alternatives exist
