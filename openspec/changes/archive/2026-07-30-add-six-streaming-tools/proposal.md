## Why

The tools/ section currently documents only 5 tools across 4 categories. Streamers routinely use a much wider ecosystem of desktop applications — streaming software, all-in-one platforms, TTS automation, and VTuber tracking. Adding coverage for these 6 popular tools makes the library more useful for both beginner and veteran streamers, and establishes the `vtubing/` category for a growing segment of the streaming community.

## What Changes

- **New tool: Streamlabs Desktop** — multi-page documentation in `tools/streaming-software/streamlabs-desktop/`
- **New tool: Meld Studio** — multi-page documentation in `tools/streaming-software/meld-studio/`
- **New tool: PolyPop** — multi-page documentation in `tools/streaming-platforms/polypop/`
- **New tool: Speaker.bot** — single-page documentation in `tools/automation/speaker-bot.md`
- **New tool: VTube Studio** — multi-page documentation in `tools/vtubing/vtube-studio/`
- **New tool: Puppetstring** — single-page documentation in `tools/vtubing/puppetstring.md`
- **New category: `tools/vtubing/`** — created with both tools inside

## Capabilities

### New Capabilities
- `streamlabs-desktop`: documentation for Streamlabs Desktop — OBS fork with built-in overlays, alerts, Cloudbot, multistream, and monetization
- `meld-studio`: documentation for Meld Studio — native (non-OBS) streaming software with cloud multistreaming, AI overlay builder (Spark), and built-in chat/alerts
- `polypop`: documentation for PolyPop — game-engine-powered streaming platform with 3D scene depth, physics-based overlays, and plugin system (Candy Pack)
- `speaker-bot`: documentation for Speaker.bot — TTS companion to Streamer.bot supporting 10+ speech engines and voice commands
- `vtube-studio`: documentation for VTube Studio — industry-standard Live2D VTuber tracking with webcam/iPhone face tracking, hand tracking, plugin API, and collab mode
- `puppetstring`: documentation for Puppetstring — open-source-adjacent VTuber tracking for Inochi2D models, cross-platform with multiple tracking methods

*(none — all new)*
