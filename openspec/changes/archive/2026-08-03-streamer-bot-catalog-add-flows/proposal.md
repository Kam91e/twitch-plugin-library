# streamer-bot-catalog-add-flows

## Why

The existing Streamer.bot reference (`tools/automation/streamer-bot/sub-actions/` and `triggers/`) was built from official docs alone and never verified against the actual application. Live exploration of Streamer.bot **v1.0.4** exposed concrete mismatches (version gaps, missing categories, undocumented single-item groups) that a docs-only reference cannot catch. Streamers also cannot learn how to *add* triggers, actions, or sub-actions from the current text — the UI flows are undocumented. This change reconciles the reference with reality and adds the missing add-flows guidance.

## What Changes

- **Verify and annotate the sub-action catalog** (`tools/automation/streamer-bot/sub-actions/`): cross-check every entry against the live app's flyout hierarchy (14 categories, 114 groups, 353 items captured from the running v1.0.4). Flag version-gated entries (e.g. Logic `Loop Continue`/`Loop Break`, StreamFog integration — v1.0.5 only) and note "single-item groups" where the group name equals the sub-action name.
- **Verify and annotate the trigger catalog** (`tools/automation/streamer-bot/triggers/`): confirm the 11 app-visible trigger sources (Core, Custom, Elgato, Integrations, Kick, Meld Studio, OBS Studio, Streamlabs Desktop, Trovo, Twitch, YouTube) and note that Trovo is absent from the official docs index while present in the app.
- **New add-flows reference** (`tools/automation/streamer-bot/add-flows.md` or a `flows/` folder): step-by-step UI flows for adding a Trigger, an Action, and a Sub-Action, based on captured dialogs and context menus (right-click → Add → picker flyout; "Add Action" dialog fields: Name, Enabled, Group, Queue, Random Action/Concurrent, Always Run, Exclude from Action Queue).
- **New Commands reference** (`tools/automation/streamer-bot/commands.md` or `commands/` folder): step-by-step UI flow for adding a Command in the Commands section (left nav → Commands; right-click grid → Add → "Add Command" dialog with Name, Enabled, Mode, Include, Command(s) multi-line prefix list, Location, Group, Options/Cooldowns/Sources tabs, Permissions with Grant Type + Group/User Permissions), including the grid columns (Name, Command, Options, Location, GCD, UCD, Enabled) and the search box above it.
- **New Twitch platform reference** (`tools/automation/streamer-bot/platforms.md` or `platforms/twitch.md`): Platforms section (left nav → Platforms) landing with 4 platform cards (Twitch, YouTube, Trovo, Kick — Trovo present here too, consistent with trigger sources). The Twitch section (verified end-to-end by live probing, including scrolling to the bottom) contains, in order: 5 feature cards (Channel Point Rewards, Polls, Predictions, Sub Counter, Videos), an Accounts section (Broadcaster Account with logged-in user + Logout; Bot Account with Login), a **Settings** subsection (Emote Handlers, First Words, Present Viewers, Gift Bombs, Pyramids, Stream Update on Connect — with toggles), and a **Related Support** subsection (Help with Twitch, Configuring Twitch). The page requires scrolling to reach Settings and Related Support.
- **Expandable cards verified (down-arrow `` behavior)**: only the two **Accounts** cards actually expand/collapse on arrow click — each reveals a "Forget this account?" row with a Forget button plus a **Services** group below (Broadcaster: Chat Client with Disconnect/Connecting status + EventSub with Disconnect; Bot: EventSub Client with Connect when no bot is logged in). The Settings cards (Emote Handlers, First Words, Present Viewers, Gift Bombs, Pyramids) and Related Support rows (Help with Twitch, Configuring Twitch) also show the `` arrow but **do not expand** — their descriptions and toggles are already visible in the collapsed state; Help with Twitch/Configuring Twitch are external-docs links. Stream Update on Connect has a toggle and **no arrow**. Feature cards (CPR, Polls, Predictions, Sub Counter, Videos) use the `>` chevron (``) and open panels on card click.
- **Captured modal-dialog structures** (live-probing v1.0.4, all verified in-app and closed cleanly):
  - "Add Action" (`actions-ctx2-uia.txt`, 600×320): Name `#textBox`, Enabled, Group `#PART_EditableTextBox`, Queue, radios Random Action/Concurrent, Always Run, Exclude from Action Queue Pending/History, Ok/Cancel.

  - "Add Trigger - Test" (`add-trigger-test-modal-uia.txt`, 600×325): **Arguments DataGrid (Name/Value columns)** — generic for parameterized trigger types, Ok/Cancel.
  - "Delete All Triggers?" (`delete-all-triggers-modal-uia.txt`, 460×168): confirm text with action name, `Don't Show Again` checkbox, Yes/No. Same pattern likely applies to "Delete All Sub-Actions".
  - "Add Command" (`add-command-modal-uia.txt`, 850×560): Name, Enabled, Mode ComboBox, Include, Command(s) multi-line edit (one prefix per line), Location ComboBox, Group ComboBox (editable), tabs Options (Ignore Bot Account, Ignore Internal Messages, Persist per User Counter, Persist Counter, Case Sensitive) / Cooldowns / Sources, Permissions panel (Grant Type ComboBox; Group Permissions tab with Available list + `>>`/`<<` + Allowed; User Permissions tab), Ok/Cancel. Context menu on the Commands grid: Add, Collapse All, Expand All (`commands-ctx-uia.txt`); grid columns: Name, Command, Options, Location, GCD, UCD, Enabled (`commands-panel-uia.txt`).
  - "Create Twitch Poll" (`new-poll-modal-uia.txt`, 600×590): Question, Response list (minimum 2, maximum 5) with Add/Del, Channel Points Per Vote (0 = disabled, spinner up/down), Duration (seconds), Create/Cancel. Opened from Platforms → Twitch → Polls panel context menu (New Poll, Refresh Polls from Twitch — `polls-ctx-uia.txt`); Polls grid columns: Title, Choices, Votes, Duration, Winner, State + "Selected Poll" combo (`polls-panel-uia.txt`).
  - "Create Twitch Prediction" (`new-prediction-modal-uia.txt`, 600×578): Start a Prediction info box, Name the prediction, Outcomes list (minimum 2, maximum 10) with Add/Del, Submission Period (seconds, spinner; note the app label shows a typo "Submission Preiod"), Create/Cancel.   - "Sub Counter" panel (`subcounter-panel-uia.txt` + scrolled): Enabled toggle, Sub Counter current value + refresh, Rollover toggle, Output File path + browse, Output Text template (multi-line), Reset Sub Counter button (destructive warning). Opened from the Sub Counter feature card.
  - "Videos" panel (`videos-panel-uia.txt` + `videos-type-dropdown.txt`): User filter, Type ComboBox (All/Archive/Highlight/Upload), Search box, "Found 0 videos" status, grid columns Title, Created At, View Count, Type, Duration. Opened from the Videos feature card.
- **Key discovery — modal vs direct-add**: parameter-less trigger types (e.g. Core "Streamer.bot Started") add **directly without any dialog**; parameterized trigger types and all sub-actions open a config modal that blocks the main window until closed. This reconciles the earlier "ADD NOT FOUND" confusion (a modal was already open and blocking UI).
- **Picker navigation mechanics** (captured): Triggers flyout is a **two-step click** flow (context menu → Add → *click* source e.g. Core → *click* trigger type); Sub-Actions flyout is a **hover-chain** flow (Add → *hover* category e.g. Core → *hover* group e.g. Actions → *click* sub-action). Trigger-source/type flyout items expose **virtualized names** in UIA (e.g. `_2va1ymb…`) — names are only realized after selection, so app-visible names come from selection + docs cross-check.
- **Version-discrepancy notes**: document where the reference reflects v1.0.5 docs vs the v1.0.4 app (Logic 6 vs 8, StreamFog, Trovo, Twitch Chat pin/unpin, Suspicious Status) so readers know what their installed version offers. Note: `Get Clip Download Urls` was initially listed as v1.0.5 but IS present in the v1.0.4 catalog dump (line 376) — documented as present, no version gate.
- **No breaking changes** to existing navigation; additions only.
