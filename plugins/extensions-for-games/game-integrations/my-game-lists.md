# My Game Lists

> Show off the games you love to play with a customisable panel that lists up to 50 games from Twitch's game library.

## Quick Start

1. Go to the [My Game Lists extension page](https://dashboard.twitch.tv/extensions/1xsl7v8xmaec0zvy98h6ysvrncrr92) on Twitch
2. Click **Install**
3. In your Creator Dashboard, go to **Extensions** > **My Extensions**
4. Click **Activate** and assign it to a panel slot
5. Click the **Configure** (gear) icon next to the extension
6. Use the search field to browse Twitch's game library and add games to your list
7. Save your changes and visit your channel to see the list displayed in the panel

You can add up to 50 games to your list. The panel displays them in a clean, scrollable format.

## Features

- **Twitch game library search** — browse and select from Twitch's official game catalogue
- **Up to 50 games** — build a comprehensive list of games you play, your backlog, favourites, or speedrun PBs
- **Panel display** — shows your curated list in a panel below your stream, visible even when offline
- **Simple search & add** — intuitive interface for finding and adding games
- **Easy management** — remove or reorder games from your list at any time

## Configuration

My Game Lists is a straightforward panel extension. Configuration is done through the extension's settings panel.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| Game Search | search | — | Type to search Twitch's game library; click a game to add it to your list |
| Added Games | list | empty | The games currently in your list, up to 50 |

### Adding Games

1. Open the extension configuration from your Extensions dashboard
2. Type in the search box to find games from Twitch's library
3. Click on a game result to add it to your list
4. Repeat until your list is complete (max 50 games)
5. Click **Save** to apply changes

### Removing Games

In the configuration view, locate the game you want to remove in your added list and click the remove/delete option next to it.

## Tips & Tricks

- **Use cases beyond game lists** — this extension is flexible: use it for a stream backlog, a wishlist, your top 10 favourite games, speedrun personal bests, or a list of games you plan to stream next
- **Panel placement** — place the panel near the top of your About section so new visitors see which games you play immediately
- **Offline utility** — since it's a panel extension, potential viewers browsing your channel while you're offline can still see your game interests
- **Update regularly** — refresh your list as you discover new games or complete old ones to keep your channel looking active
