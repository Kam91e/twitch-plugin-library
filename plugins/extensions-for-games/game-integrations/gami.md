# Gami

> Display detailed information about the game currently being played on your channel, including cover art and metadata.

## Quick Start

1. Go to the [Gami extension page](https://dashboard.twitch.tv/extensions/541swugz9n0xaar6drfppfovjj34q5) on Twitch
2. Click **Install**
3. In your Creator Dashboard, go to **Extensions** > **My Extensions**
4. Find Gami and click **Activate** — it installs as a panel
5. Assign it to one of your panel slots (Panel 1, 2, or 3)
6. Visit your channel page — Gami automatically detects the game you're playing and displays its title, cover art, and related information

No additional configuration is required. The extension pulls game data from IGDB and speedrun.com in real time.

## Features

- **Automatic game detection** — displays the game you're currently streaming without manual updates
- **Cover art display** — shows the game's box art or cover image directly in the panel
- **IGDB integration** — pulls rich metadata from the Internet Game Database (IGDB)
- **Speedrun.com integration** — optionally shows speedrun data for supported games
- **Lightweight panel** — minimal footprint that integrates cleanly into your Twitch About section
- **Real-time updates** — automatically switches the display when you change games mid-stream

## Configuration

Gami is designed as a plug-and-play extension with minimal settings. It works out of the box once installed and activated.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| No configurable options | — | — | Gami auto-detects the game and displays info without user configuration |

### Behaviour Notes

- The extension reads your channel's current game/category from Twitch's API
- It displays the game's name and cover art in a clean panel layout
- If you are not live or have not set a category, the panel shows a default neutral state

## Tips & Tricks

- **Works offline too** — since Gami is a panel extension, it remains visible even when you're not streaming, showing the last detected game
- **Multi-game streams** — if you switch games during a broadcast, Gami updates automatically within a few seconds
- **Combine with other panels** — pair Gami with a schedule or social link panel for a complete About section
