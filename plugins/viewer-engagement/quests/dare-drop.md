# Dare Drop: Dare & Pledge Alert Overlay

> Let viewers challenge you with dares backed by pledges — a real-time overlay and Twitch panel that turns audience challenges into interactive stream content.

![Dare Drop dashboard](https://cdn.prod.website-files.com/647d11647af15cf48723cd4b/64b60f9ccbb311f07eb2bbad_Screenshot%20from%202023-06-09%2015-56-43%20(1)%20(1).avif)

## Quick Start

1. **Create a Dare Drop account** at [daredrop.com](https://daredrop.com/) and authenticate via Twitch.
2. Go to [daredrop.com/alerts](https://daredrop.com/alerts) to get your **OBS Overlay** and **Audio Alert** browser source URLs.
3. Add the browser source URL to **OBS, Streamlabs Desktop, Twitch Studio, Xsplit, or GameShow**.
4. Install the **Twitch Panel Extension** from [daredrop.com/extensions](https://daredrop.com/extensions) — activate it in a panel slot.
5. Create a few **starter dares** so viewers understand how it works.
6. Set up a `!dares` chatbot command linking to your Dare Drop profile.
7. Add a **PayPal payout email** in your Dare Drop account settings.

## Features

- **Dare system:** Viewers submit challenges backed by monetary pledges or game rewards. You accept or reject them.
- **OBS overlay:** Live feed of active dares and pledges on stream — builds hype for challenges you've accepted.
- **Audio alerts:** Custom sounds play when dares are created or pledges are made.
- **Twitch panel extension:** Shows active dares, lets viewers create new dares, pledge Bits, and see a Top Pledgers leaderboard.
- **Crowdfunding:** Once you accept a dare, set a funding goal and let your broader audience contribute.
- **Publisher Drops:** Game publishers post bounties — win game keys, DLC, and merch for completing in-game challenges.
- **Moderation controls:** Auto-filter for offensive content plus manual accept/reject from the Twitch panel or website.
- **Flexible proof delivery:** Submit proof via live stream VOD, Twitch clip, YouTube video, or Facebook clip.
- **25-day window:** Dares remain live for 25 days after creation.

| Audio alerts | [daredrop.com/alerts](https://daredrop.com/alerts) | Upload custom sounds, test buttons |
| Panel extension | [daredrop.com/extensions](https://daredrop.com/extensions) | Install Twitch panel extension |

| Content filter | Dare Drop dashboard | Auto-filter offensive content |
| Payout email | Dare Drop account settings | PayPal email for completed dares |

**Pricing:** Free to join. Dare Drop takes a 10% fee on completed dares only.

## Tips & Tricks

- **Create starter dares:** Viewers are more likely to participate when they see examples of what kind of dares you accept.
- **Use a `!dares` chatbot command:** Regularly promote your Dare Drop profile with Nightbot, StreamElements, or Streamlabs Cloudbot.
- **Audio troubleshooting:** If audio alerts aren't working, refresh the browser source cache or toggle "Browser Source Hardware Acceleration" in OBS Settings → Advanced.
- **Publisher Drops add variety:** Accepting publisher bounties alongside viewer dares keeps content fresh.
- **Creators report 2–3× longer streams** thanks to Dare Drop engagement, and some grew from 3 to 15 average concurrent viewers in under 2 months.
- **Dares can be crowdfunded:** If a dare is expensive, set a crowdfunding goal so multiple viewers can contribute.

## Alternatives

Dare Drop is unique in combining fan-submitted challenges with monetary pledges and real-time overlay alerts. Closest alternatives:

- **[Sound Alerts](../streamer-tools/alerts/sound-alerts.md)** — Viewer-triggered sounds via Bits, similar real-time alerts but no dare/quest system.
- **[Streamlabs](../all-in-one-interactions/streamlabs.md)** — All-in-one overlay with polls, giveaways, and mini-games — different engagement mechanism.
- **Crowd Control** — Viewers spend Bits/Channel Points to affect the streamer's gameplay (spawn enemies, add buffs). Different mechanic but similar viewer-created challenge feel.
