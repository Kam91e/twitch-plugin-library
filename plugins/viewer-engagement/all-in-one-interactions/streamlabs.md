# Streamlabs

> An all-in-one overlay extension that keeps viewers engaged with loyalty points, mini-games, polls, song requests, and giveaways — all in a single interactive menu.

![Streamlabs Extensions](https://cdn.prod.website-files.com/63e1a94f5639fece8d871b6f/69b07c04eb5a8806ca234963_extensions-og-image.png)

## Quick Start

1. Go to your Twitch **Creator Dashboard** → **Extensions** → **Discover**.
2. Search for "Streamlabs" and click **Install** on the main Streamlabs overlay extension.
3. Click **Configure** — toggle which features you want (loyalty points, mini-games, polls, song requests, giveaways) and customise colours to match your brand.
4. Go to **My Extensions**, find Streamlabs, and click **Activate** → select **Overlay 1** (the only overlay slot).
5. Go live! The overlay appears as a transparent interactive menu on your stream. Viewers can click to earn points, play games, vote, and more.

> **Important:** Twitch allows only one overlay extension at a time. This extension bundles multiple features into that single slot.

## Features

- **Loyalty Points System:** Viewers earn points by watching. Random treasure chests appear on screen — clicking them awards bonus points. No chat commands needed.
- **Mini-Games:** Scratchers, Pick-a-Card, Treasure Chests, and more. Viewers can play solo or as a group.
- **Polls:** Create polls from the Streamlabs Dashboard / Recent Events. Viewers vote by clicking in the overlay.
- **Giveaways:** Created via Streamlabs Dashboard. Viewers enter by clicking a toast notification. Winner is randomly chosen.
- **Song Requests:** Integrated with SoundCloud API. Viewers search and add songs to a queue. Broadcaster controls: autoplay, shuffle, volume, skip, re-order.
- **Custom Rewards:** Set up custom and automated loyalty point rewards. Redeemed items appear in Recent Events / Streamlabels.
- **Customisable Branding:** Choose which features to show. Customise colours, menu appearance, and chest icons.
- **Bits-in-Extensions Support:** Viewers can use Bits in polls, mini-games, and other interactions (80% streamer, 20% Streamlabs revenue split).
- **Mobile Support:** Available for mobile viewers on Twitch iOS and Android apps.

## Configuration

| Setting | Location | Description |
|---|---|---|
| Feature toggles | Configure panel | Enable/disable loyalty points, mini-games, polls, song requests, giveaways |
| Colours | Configure panel | Overlay menu colours to match your brand |
| Chest icons | Configure panel | Appearance of treasure chests that award loyalty points |
| Menu appearance | Configure panel | Layout and positioning of the viewer-facing menu |
| Loyalty payout interval | Streamlabs Dashboard | How often points are awarded (in minutes) |
| Loyalty payout amount | Streamlabs Dashboard | Points per interval |
| Event payouts | Streamlabs Dashboard | Bonus points for follows, subs, hosts, raids |
| Music controls | Streamlabs Recent Events | Autoplay, shuffle, volume, queue management |
| Polls & giveaways | Streamlabs Dashboard | Creation, entry conditions, duration |

## Tips & Tricks

- **Best use of your one overlay slot:** Since Twitch only allows one overlay extension, this is an efficient choice — it bundles loyalty, polls, games, and music into that one slot rather than needing separate extensions.
- **Combine with Streamlabs Leaderboard:** Install the Leaderboard panel extension alongside it so viewers can see who's earning the most points, driving competition.
- **Use Cloudbot for deeper loyalty features:** Streamlabs Cloudbot integrates with the extension for heists, duels, gambling mini-games, and emote combos.
- **Treasure chests keep viewers watching:** Random chests that appear and disappear after a few seconds keep viewers engaged and focused on the stream.
- **Music requires Recent Events open:** The song request feature needs the Recent Events panel open (website or Streamlabels).
- **Works on mobile too:** Mobile viewers on Twitch apps can see and use the overlay, interact with loyalty points, and play mini-games.
