# WizeBot - Viewer Card

> Let each viewer see their own channel stats — level, rank, XP, watch time, and messages — displayed in a real-time profile card in your channel's panel section.

## Quick Start

1. **Create a WizeBot account** at [wizebot.tv](https://wizebot.tv/) and connect your Twitch channel.
2. Go to the **WizeBot panel** → **Rank System** and enable at least one ranking system (Level or Rank).
3. Go to your Twitch **Creator Dashboard** → **Extensions**, find "WizeBot - Viewer Card", and click **Install**.
4. Activate it as a **Panel** extension (Panel 1, 2, or 3).
5. Go live — viewers who authenticate with Twitch will see their personal stats in the card.

> **Important:** The Rank & Level system must be enabled in the WizeBot panel, otherwise the extension will show "The system is disabled on this channel."

## Features

- **Personal viewer stats:** Shows each viewer's current level, rank, XP, watch time, and total messages — visible only to the authenticated viewer.
- **Progress tracking:** Displays XP progress toward the next level, encouraging continued engagement.
- **Real-time updates:** Stats update in real-time as viewers earn XP and level up during live streams.
- **Custom rank titles:** Streamers can create custom rank names and XP thresholds in the WizeBot panel.
- **Free to use:** No premium WizeBot account required for the extension to work.

## Configuration

| Setting | Location | Description |
|---|---|---|
| Rank System | WizeBot panel → `interaction_rank_system` | Enable Level or Rank system |
| Level thresholds | WizeBot panel | Custom XP amounts per level |
| Rank titles | WizeBot panel | Custom names for each rank tier |
| XP rates | WizeBot panel | How much XP viewers earn per minute of watching |
| Anti-AFK | WizeBot panel | Require chat activity to earn XP |

## Tips & Tricks

- **Enable the Rank system first** — the most common issue is forgetting to activate a ranking system in the WizeBot panel. The extension will say "The system is disabled" until you do.
- **XP only during live streams:** Viewers only earn progress while you are live, not during offline or reruns.
- **Data delay:** After enabling the Rank system, allow up to 12 hours or one live stream session for data to appear.
- **Viewers must authenticate:** Each viewer needs to click "grant permissions" on the panel to see their own stats.
- **Custom ranks drive engagement:** Creating fun, channel-specific rank titles gives viewers a goal to work toward.
