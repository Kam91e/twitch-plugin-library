# MyEmotes

> A panel extension that displays your Twitch channel's emotes and badges, including subscriber tiers and third-party emote support.

![MyEmotes panel showing emotes and badges](https://grablabs.com/static/media/MyEmotes-Screenshot-1024x768-1.35979ba1.jpg)
![MyEmotes configuration and theme options](https://grablabs.com/static/media/MyEmotes-Screenshot-1024x768-2.b31320ca.jpg)

## Quick Start

1. Go to the [MyEmotes Twitch Extension page](https://dashboard.twitch.tv/extensions/grhpdp2owc0kzdn0djjsghlfk4ld4v-2.0.5)
2. Click **Install**
3. Open your **Creator Dashboard** → **Extensions** → **MyEmotes**
4. Choose a theme: **Light**, **Dark**, or **Match Twitch Theme**
5. That's it — your emotes and badges populate automatically

## Features

- **Full emote display** — Shows follower, subscriber, and bit tier emotes in one panel
- **Badge section** — Displays all channel badges
- **Automatic updates** — New emotes appear without any manual maintenance
- **Third-party emote support** — Integrates with BetterTTV, FrankerFaceZ, and 7TV
- **Collapsible tiers** — Viewers can expand/collapse each subscription tier
- **Quick subscribe** — Viewers can subscribe or follow directly from the panel
- **Copy emote codes** — One-click copy for easy chat use
- **Theme options** — Light mode, dark mode, or auto-match the viewer's Twitch theme

## Configuration

| Setting | Options | Default | Description |
|---------|---------|---------|-------------|
| Theme | `light`, `dark`, `auto` | `auto` | Panel appearance — auto matches viewer's Twitch theme |
| Emote section | `show`, `hide` | `show` | Toggle the emote display section |
| Badge section | `show`, `hide` | `show` | Toggle the badge display section |
| Collapsible tiers | `on`, `off` | `on` | Allow viewers to collapse/expand sub tiers |
| Third-party emotes | `on`, `off` | `on` | Include BTTV, FFZ, and 7TV emotes |

Configuration is done directly in the Twitch Extension panel after installation — no external dashboard needed.

## Tips & Tricks

- **Set it and forget it:** MyEmotes updates automatically, so you never need to manually add new emotes or badges
- **Auto theme is best:** The `auto` theme setting matches each viewer's personal Twitch theme, so everyone sees what they're comfortable with
- **Combine with loyalty:** Pair this plugin with a channel points system so viewers have more ways to earn and show off their emotes
- **Third-party sync:** If you use BTTV, FFZ, or 7TV, enable third-party emotes so everything shows in one place

## Alternatives

- [Emotes Showcase](https://dashboard.twitch.tv/extensions/...) — similar emote display panel, lighter feature set
- [7TV](https://7tv.app/) — broader third-party emote platform (not just a panel, but a full emote ecosystem)
- [FrankerFaceZ](https://www.frankerfacez.com/) — custom emotes platform, used alongside MyEmotes rather than instead of
- [BetterTTV](https://betterttv.com/) — browser extension for additional emotes, different use case (chat-side, not panel)
