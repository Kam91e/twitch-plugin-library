# 7TV Emotes

> "The Emote Platform for All" — A free browser extension and web platform that lets streamers manage hundreds of custom emotes across Twitch and Kick with real-time updates, plus chat enhancements.

## Quick Start

7TV works for both **viewers** and **streamers**. Get emotes working in under a minute.

### For Viewers

1. Visit [7tv.app](https://7tv.app/) and click **Download**
2. Install the browser extension for your browser (Chrome, Firefox, Edge, Opera)
3. Refresh any open Twitch tabs — 7TV emotes appear automatically in chat

### For Streamers (Adding Channel Emotes)

1. Visit [7tv.app](https://7tv.app/) and sign in with your Twitch account
2. Click **Emote Sets** and create a new set — name it after your channel
3. Browse the [emote library](https://7tv.app/emotes) or upload your own custom emotes (PNG / GIF / WebP, max 2.5 MB)
4. Right-click any emote → **Add to [your set name]**
5. Go to your set's settings and set it as the **active/default set** for your channel
6. Your emotes now appear in chat when viewers type the emote codes

## Features

- **1,000 free emote slots per channel** — the largest slot count among third-party emote platforms
- **Emote Sets** — group emotes into custom, shareable, and swappable sets for different moods, events, or games
- **Real-time updates** — adding or removing emotes updates instantly across all viewers without a page refresh
- **Next-gen image formats** — WebP and AVIF support for faster loading and lower bandwidth
- **Animated emotes** — supports GIF, WebP, and WebM animated formats
- **Wide and zero-width emotes** — create creative multi-emote layouts and overlays in chat
- **Built-in emote menu** — type `;` in chat to trigger auto-completion and browse available emotes
- **Integrated BTTV and FFZ support** — natively renders FrankerFaceZ emotes without needing the FFZ extension
- **Chat performance improvements** — rebuilt chat rendering engine for smoother scrolling at high message volumes
- **Highlight system** — highlight messages by username, badges, or keywords
- **Stream stats overlay** — show real-time latency, resolution, and bitrate
- **Multi-platform** — works on Twitch, Kick, and YouTube
- **Viewer chat commands** — `/search`, `/add`, `/remove`, `/rename`, `/nuke` (for moderators)
- **Paid subscription extras** — personal emotes, name paints, animated profile picture, subscriber badge, zero-width emote access

## Configuration

### Emote Set Management (Web Platform)

| Setting | Description |
|---------|-------------|
| Set Name | A label for your emote set (e.g., "Main", "Sub Sunday", "Meme Night") |
| Default Set | Which set is active on your channel — only one default at a time |
| Moderator Permissions | Grant trusted moderators the ability to add/remove emotes from your sets |
| Editor Permissions | Full edit access to modify, create, and delete sets |
| Emote Slot Usage | Track how many of your 1,000 slots are used per set |

### Browser Extension Settings

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| Emote Menu Position | dropdown | `Bottom` | Where the emote picker appears in chat (Bottom / Top / Left / Right) |
| Emote Scale | slider | `100%` | Adjust the size of emotes displayed in chat |
| Chat Font Size | slider | `100%` | Global chat font size multiplier |
| Highlight Messages | toggle | `Off` | Enable message highlighting by username, badge, or keyword |
| Stream Stats | toggle | `Off` | Show an overlay with stream latency, resolution, and bitrate |
| Video Player Click Actions | dropdown | `Default` | Customise double-click and right-click behaviour on the video player |
| FFZ Integration | toggle | `On` | Enable native rendering of FrankerFaceZ emotes |
| BTTV Integration | toggle | `On` | Enable BetterTTV emote rendering (requires BTTV extension) |

### Chat Commands (Moderators)

| Command | Usage | Description |
|---------|-------|-------------|
| `/search <query>` | `/search pogchamp` | Search the global emote library |
| `/add <code>` | `/add CatJam` | Add an emote to the channel's active set |
| `/remove <code>` | `/remove CatJam` | Remove an emote from the channel's active set |
| `/rename <old> <new>` | `/rename CatJam DogJam` | Rename an emote in the active set |
| `/refresh` | `/refresh` | Force-refresh the emote set for all viewers |
| `/nuke <emote>` | `/nuke CatJam` | Remove all instances of an emote from chat history (mod only) |

## Tips & Tricks

- **FFZ integration is automatic** — 7TV renders FrankerFaceZ emotes natively, so your viewers don't need to install FFZ separately. 7TV users will see FFZ emotes without any extra setup.
- **Quick add from library** — right-click any emote on [7tv.app/emotes](https://7tv.app/emotes) to instantly add it to any of your emote sets. No need to open the set editor.
- **1,000 slots per channel, not per account** — if you stream on multiple channels, each channel gets its own 1,000-slot pool. Create different sets for different channels.
- **Global emotes work without streamer setup** — even if a streamer hasn't configured 7TV, viewers can still see global 7TV emotes in chat (emotes that are part of the global set).
- **Mobile use requires a third-party app** — 7TV does not have an official mobile app. Use **Chatsen** (iOS) or **Frosty** (Android) for 7TV emote support on mobile.
- **Combine with BTTV** — BetterTTV has a dedicated 7TV integration toggle in its settings. Enable it to see both platforms' emotes seamlessly.
- **Create themed sets for events** — build separate emote sets for subathons, holiday streams, or game-specific broadcasts and swap them instantly from [7tv.app](https://7tv.app/).
- **Emote menu shortcut** — type `;` in any Twitch chat to open the 7TV emote picker, then keep typing to search — no need to click a button.

## Alternatives

- [BetterTTV (BTTV)](https://betterttv.com) — the most widely installed third-party emote platform with the largest global emote library. Choose BTTV if you want maximum viewer adoption.
- [FrankerFaceZ (FFZ)](https://frankerfacez.com) — the original third-party emote platform with deep chat customisation and a long-standing community. Choose FFZ if you prefer older, well-established emotes and custom chat styling.
- [MyEmotes](./myemotes.md) — a Twitch Panel Extension that lists a channel's existing emotes in an overlay panel. Different use case: display rather than management.
- **Twitch Native Sub Emotes** — built into Twitch with no installation needed. Limited slots, no animation support, but guaranteed to work for every viewer without extensions.
