# Streamlabs Leaderboard

> A Twitch panel extension that displays your top supporters across multiple categories — bits, loyalty points, subscriptions, gifted subs, chat activity, and emotes — with a special design for the #1 spot.

![Streamlabs Leaderboard appearance example](https://contenthub-cdn.streamlabs.com/static/imgs/1*l6LxDzJ03dLWoiq8TUFHRQ.png)

## Quick Start

1. Go to your Twitch **Creator Dashboard** → **Extensions** → **Discover**.
2. Search for "Streamlabs Leaderboard" and click **Install**.
3. Go to the **My Extensions** tab, find Streamlabs Leaderboard, and click **Activate**.
4. Choose a panel slot: **Panel 1**, **Panel 2**, or **Panel 3**.
5. The extension now appears as a panel on your channel's **About** page.
6. Click the gear icon to configure — choose your default tab, time period, theme, and colours.

> **Note:** Requires Streamlabs Loyalty system to be active for loyalty points tracking.

## Features

- **Multiple leaderboard categories:** Bits (cheer amount), Loyalty points, Subscriptions (months subbed), Gifted subs, Chat message count (top chatters), Top emotes used in channel
- **#1 position emphasis:** The top spot gets a special prominent design to encourage competition
- **Dark or light theme:** Toggle between visual themes to match your channel
- **Custom styling:** Custom colours and font
- **Configurable default tab:** Choose which leaderboard viewers see first
- **Configurable time period:** Session, Week, Month, or All-time
- **Max items display:** Control how many leaderboard entries are shown
- **Transparent amounts:** Viewers can see exactly how much they need to climb the ranks

## Configuration

| Setting | Options | Description |
|---|---|---|
| Theme | Dark / Light | Visual theme for the panel |
| Default tab | Bits / Loyalty / Subs / Gifts / Chatters / Emotes | Which leaderboard shows first |
| Time period | Session / Week / Month / All | Time range for rankings |
| Max items | 1–50 | Number of leaderboard entries displayed |
| Custom colours | Hex colour picker | Panel colour scheme |
| Custom font | Font selector | Panel font style |

## Tips & Tricks

- **Position near the top:** Place the leaderboard panel high on your About page so viewers see it without scrolling.
- **Weekly resets drive competition:** Setting the time period to "Week" creates recurring competition as leaderboards reset, encouraging viewers to engage each week.
- **Exclude bots:** Add bot usernames (Streamlabs, Nightbot, etc.) to your Streamlabs filter list so they don't dominate the leaderboard.
- **Pair with alerts:** Sync leaderboard with Streamlabs Alert Box to call out when someone climbs into the top spots.
- **Boost chat activity:** Testers saw ~20% more chat activity when leaderboards ran live, especially with weekly resets.

## Alternatives

- **[StreamElements Leaderboards](streamelements-leaderboards.md)** — Also free. More feature-rich with loyalty store integration, stream schedule + countdown, and viewer location maps.
- **[WizeBot - LeaderBoard](wizebot-leaderboard.md)** — Free panel extension for streamers using the WizeBot ecosystem with XP-based rank and level system.
- **Twitch Built-in Leaderboards** — Native feature under Monetisation > Community > Leaderboards. Tracks Top Cheerers, Top Gifters, and Top Clippers in chat (no panel display).
