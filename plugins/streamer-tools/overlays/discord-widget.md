# Discord Widget

> Display your Discord server's online members, their statuses, and current game — a simple panel extension that shows the size of your community on your Twitch channel.

## Quick Start

1. Go to your Twitch **Creator Dashboard** → **Extensions** → **Discover**.
2. Search for "Discord Widget" by LPSX and click **Install**.
3. Go to **My Extensions**, find Discord Widget, and click **Activate**.
4. Assign it to a **Panel slot** (Panel 1, 2, or 3).
5. Enter your Discord Server ID and/or widget invite code in the configuration panel.
6. The panel will now display your Discord server's online members on your channel page.

> **Note:** This extension is currently in **HIDDEN** state on Twitch and may not appear in public search results. You may need the direct install link above.

## Features

- **Online member count:** Shows how many users are currently online in your Discord server.
- **User statuses:** Displays online, idle, and offline status of Discord members.
- **Current game:** Shows what game each Discord user is currently playing.
- **Panel display:** Appears in the panels section below your video player.
- **Open source:** Licensed under MIT — source available on GitHub.

## Configuration

| Setting | Description |
|---|---|
| Discord Server ID | Your Discord server's unique ID (enable Server Widget in Discord settings first) |
| Widget invite code | Optional — custom invite code for your Discord server |

## Tips & Tricks

- **Enable Server Widget first:** Go to your Discord server settings → Server Settings → Widget → enable "Enable Server Widget" for the extension to access your server data.
- **Place near the top:** Position the panel high on your About page so visitors see your community size immediately as social proof.

## Alternatives

- **Discord Streamkit Overlay** (by Discord) — An OBS/XSplit browser source, not a Twitch Extension. Shows voice chat, text chat, or status widgets on stream. Free. [Official site](https://streamkit.discord.com/overlay)
- **Discord Server Widget by suhodolskiy** — A similar open-source Twitch panel extension for displaying Discord server info. Free.
