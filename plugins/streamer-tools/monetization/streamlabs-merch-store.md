# Streamlabs Merch Store

> Sell your custom merchandise directly from your Twitch profile — a panel extension that lets viewers browse, select sizes, and check out without leaving Twitch.

![Streamlabs Merch Store panel](https://www.kitguru.net/wp-content/uploads/2019/03/Streamlabs_Merch_Extension_Twitch-1.png)

## Quick Start

1. **Set up your merch store** at [Streamlabs.com](https://streamlabs.com/dashboard#/merchadmin) — drag and drop an image to auto-create products (t-shirts, hoodies, mugs, hats) or create individual items.
2. Go to your Twitch **Creator Dashboard** → **Extensions** and search for "Streamlabs Merch Store".
3. Click **Install**, then go to **My Extensions**.
4. Click **Activate** and assign to a **Panel slot** (Panel 1, 2, or 3).
5. Products will auto-appear in the panel within a few minutes.
6. (Optional) Enable merch purchase alerts in Streamlabs Alert Box.

## Features

- **In-panel shopping:** Viewers scroll through products, filter categories, select sizes and colours, and check out without leaving Twitch.
- **Print-on-demand:** No inventory, no upfront cost, no minimum orders. You set the price above base cost.
- **Automated alerts:** Merch purchases can trigger on-stream alerts via Streamlabs Alert Box — streamers who enable alerts see 32% higher sales.
- **Limited edition timers:** Display countdowns for limited-run merchandise.
- **Storefront customisation:** Choose layout (Clean/Grid/Cards), custom banner (1106×508 px), colours, fonts, and theme.
- **Multiple product types:** T-shirts, hoodies, mugs, hats, and more — dropship to 3 fulfilment centres (2 US, 1 Europe).
- **Cloudbot integration:** Built-in `!merch` command and timed promotion timers.

## Configuration

| Setting | Location | Description |
|---|---|---|
| Products | Streamlabs Merch Dashboard | Create items, set name, price, profit margin, expiration date |
| Layout | Storefront → Layout tab | Template (Clean/Grid/Cards), header (avatar or text), banner image |
| Colours | Storefront → Colour & Font tab | Theme, background colour, font, font colour |
| Alerts | Streamlabs Alert Box | Enable/disable merch purchase alerts, custom images, message templates |
| Chatbot | Streamlabs Cloudbot | `!merch` command and timed promotion timers |

**Pricing model:** Set your own price above minimum retail. At minimum = $0 profit. Above minimum = you keep 100% minus PayPal fees. Streamlabs Ultra subscribers get higher profit margins and can upload custom product photos.

## Tips & Tricks

- **Enable merch alerts:** Streamers who enable purchase alerts see an average of 32% increase in merch sales.
- **Use `!merch` command:** Cloudbot's built-in `!merch` command lets viewers get a link in chat — enabled by default.
- **Buy your own merch at-cost:** Log into your dashboard to get the lowest price — wear it on stream as organic promotion.
- **Descriptive product names help SEO:** Google indexes merch product pages, so clear names improve discoverability.
- **Use Canva or Fiverr** if you don't have a logo yet — you just need one image to get started with the Evergreen bundle.
